# TechCore

TechCore es una aplicación web en desarrollo construida con **Next.js**, **React** y **TypeScript**, con integración de **PostgreSQL** y herramientas de acceso a datos.

## Tecnologías

- Next.js
- React
- TypeScript
- PostgreSQL
- Drizzle ORM
- Tailwind CSS

## Requisitos

- Node.js y npm
- Una instancia de PostgreSQL para las funciones que dependan de la base de datos

## Desarrollo local

1. Clona el repositorio.
2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Configura las variables de entorno que requiera la aplicación y la conexión a PostgreSQL según la configuración del proyecto.
4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

## Scripts disponibles

- `npm run dev`: inicia el servidor de desarrollo.
- `npm run build`: genera la compilación de producción.
- `npm run start`: inicia la aplicación compilada.
- `npm run lint`: ejecuta ESLint.
- `npm run typecheck`: comprueba los tipos de TypeScript.

## Estado

Proyecto en desarrollo. La configuración y las funciones disponibles pueden cambiar.
